# GAME DESIGN — PEQUEÑO CHAÑAR V0.1

## Bucle principal

MIRAR → TOCAR → DESCUBRIR → RECORDAR → AVANZAR

## Primera misión

### CONOCER EL TERRITORIO

Objetivo emocional: “Quiero mirar qué hay acá.”

Objetivo de aprendizaje indirecto:
- reconocer el río Neuquén;
- reconocer el paisaje árido;
- descubrir que el territorio tiene vida.

## Primera escena

Tres descubrimientos:
1. RÍO NEUQUÉN
2. VIENTO
3. CHAÑAR

Cada descubrimiento:
- responde al toque;
- produce una pequeña animación;
- muestra una frase corta;
- queda registrado.

Cuando se descubren los tres, aparece el avance.

## Sin puntos

No hay monedas, vidas ni castigos.

El premio es haber descubierto.

## Guardado

localStorage:
- descubrimientos;
- misión actual;
- sonido;
- gráficos;
- progreso.

- teclado básico;

- botón de menú;
